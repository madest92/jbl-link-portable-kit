# jbl-assist — помощник Алисы

Алиса хорошо ставит таймеры и включает музыку, но на многие вопросы отвечает «не знаю». Помощник подхватывает такие вопросы и отвечает на них её же голосом, с помощью нейросети [Exa](https://exa.ai), которая ищет ответ в интернете.

## Как пользоваться

Спросите через нейросеть напрямую:

- «Алиса, спроси у нейросети, кто сейчас канцлер Германии»
- «Алиса, загугли, когда следующее солнечное затмение»
- «Алиса, найди в интернете рецепт плова»

Или просто спросите Алису: если она собирается ответить «не знаю» или «ничего не нашлось», колонка скажет «Спрошу у нейросети» и ответит сама.

После ответа колонка спросит «Что-нибудь ещё?» и послушает несколько секунд:

- уточните — «а сколько ему лет?», и она ответит, помня разговор;
- скажите «нет, спасибо» или промолчите — разговор закончится;
- «Алиса, новый разговор» — начать заново.

Помощник знает дату, время и примерное место колонки, поэтому вопросы вроде «кто играл вчера» или «где поблизости поесть» работают как надо.

## Установка

Нужны колонка, подготовленная `setup.sh` ([README набора](../README.md)), и ключ Exa — его можно получить на [dashboard.exa.ai](https://dashboard.exa.ai). Сохраните ключ в файл и выполните из корня набора:

```sh
EXA_KEY_FILE=~/exa.txt sh assist/deploy.sh
```

Готовый бинарник скачается из последнего релиза. Если на компьютере есть Go 1.25+, помощник соберётся из исходников; выбрать явно — `--download` или `--build`. Сменить ключ — та же команда с новым файлом; без `EXA_KEY_FILE` ключ на колонке не меняется.

## Управление

```sh
ssh jbl 'sh /data/jbl-assist/service.sh status'     # работает ли
ssh jbl 'sh /data/jbl-assist/service.sh disable'    # выключить совсем
ssh jbl 'sh /data/jbl-assist/service.sh enable'     # включить снова
ssh jbl 'tail -n 30 /tmp/jbl-assist.log'            # что происходило
ssh jbl 'sh /data/jbl-assist/service.sh debug on'   # писать в журнал и сами фразы (off — выключить)
```

Проверить ключ и интернет без голоса:

```sh
ssh jbl '/tmp/jbl-assist/jbl-assist ask "кто сейчас канцлер германии"'
```

Помощник не меняет прошивку и саму Алису: выключенный, он не оставляет следов. Удалить — `disable`, затем `ssh jbl 'chattr -i /data/jbl-assist/exa.key; rm -rf /data/jbl-assist'`.

Вопросы и ответы попадают в журнал только с `debug on`; журнал и история разговора лежат в памяти колонки и пропадают при перезагрузке.

## Для разработчиков

```sh
sh assist/build.sh                     # тесты и сборка: build/jbl-assist.gz
EXA_KEY_FILE=ключ JBL_ASSIST_RUN=/tmp/ja go -C assist run . ask 'вопрос'   # с компьютера
```

Фразы-триггеры, тексты колонки и промпты — в [config.go](config.go). Как устроено: служба читает события Алисы с локального порта 9875 (распознанный текст и её ответ приходят ещё до речи), отменяет её ответ и говорит свой текст её голосом через порт 9910. Команды бинарника — `jbl-assist` без аргументов.
